Install Fasting Shift on Android

Fasting Shift is in Android beta. A public Google Play download is pending.

Already using Fasting Shift? Before changing builds, save a backup to Downloads from Settings → Privacy and data → Back up to a file. On older versions, open Settings → Back up to a file. Check that you can find the file in Downloads. If Android refuses the update, keep the existing app and backup until you have checked the installation instructions for the new build.

  1. Copy your invite link or code.
  2. Open the current tested beta build and select Staging APK (GitHub sign-in required). Extract the APK if it downloads as a ZIP. If the tested file has expired, ask the sender for a fresh build.
  3. After a fresh install, complete setup and choose Settings → Privacy and data → Restore from a backup. Select your saved file, confirm the replacement, and check your history and running timer.
  4. Return to this invite on your Android phone and tap Open in Fasting Shift. On your first visit, finish screening. Choose the invitation’s schedule or Follow my own plan, then tap Join. To enter it manually, go to History → Challenges → Have an invite link? and paste the code.
