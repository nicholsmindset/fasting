Joining for the first time?

Fasting Shift is in Android beta. A public Google Play download is pending.

  1. Copy your invite link or code.
  2. If you need the app, download the staging build from GitHub (sign-in required). Open the downloaded APK to install it. If GitHub gives you a ZIP, extract the APK first. If the link has expired, ask the sender for the current build.
  3. Return to this invite on your Android phone and tap Open in Fasting Shift. On your first visit, finish screening to see the invitation. To enter it manually, go to History → Challenges → Have an invite link? and paste the code.
